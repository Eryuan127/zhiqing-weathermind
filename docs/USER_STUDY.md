# 待实施用户任务测试

状态：只有方案，没有招募参与者，没有真实用户结果。

建议邀请5至8名同学，取得同意后使用匿名编号，不记录密码、GPS、真实姓名。比较两种方式：仅看天气首页与使用助手。随机或交替安排先后顺序，减少学习效应。对比使用同一地点、同一时刻冻结的天气输入，并标记是快照而非实时天气。

任务：1 查明天下午是否需带伞；2 为明天下午连续两小时跑步选时段；3 将同一安排改到另一城市；4 拒绝定位后手动选城；5 说明下一小时模型适用范围和误差含义。

记录：完成/未完成、耗时秒、操作次数、是否请求帮助、是否误读预报为实测、满意度1至5、失败原因。事先规定完成判据：城市/日期/时段正确且找到有证据的结果。分别报告中位耗时、完成比例、原始记录和失败案例。小样本只能作为可用性探索，不宣称统计显著。

任务完成后询问：最难理解的术语、最难找到的入口、是否知道数据更新时间。记录表为空白CSV，后续由真实观察填写，禁止自动生成用户结果。
