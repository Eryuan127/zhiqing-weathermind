# Qwen 输入压缩对比

保留每轮“理解规划 + 回答生成”两次调用，仅精简提示词和模型输入。结构化状态保留已确认城市、日期、时段、活动和偏好；发送最近两轮用户问题及最后一轮助手回答（最多240字）。数据库历史不删除。

## 实测

同一模型、同一组输入状态、相同的合成天气依据，修改前后各测一次。以下合计均包含两次调用的输入和输出 token。

| 场景 | 修改前 | 修改后 |
|---|---:|---:|
| 跑步建议 | 3094 | 2124 |
| 穿衣建议 | 3073 | 2088 |
| 长袖长裤追问 | 3086 | 2133 |

平均 3084 → 2115 token，减少 31.4%。三组意图均符合预期，回答生成与数值引用校验通过。

这只是三组场景的单次实测，不能视为固定节省比例、准确率评估或天气预报验证。输出长度和后续历史会影响用量。更早对话原文不再发送，详细回忆可能受限；已确认条件仍由结构化会话状态保留。

验证：162项单元/回归测试通过。原始对比记录见 artifacts/qwen-compaction-comparison.json。
